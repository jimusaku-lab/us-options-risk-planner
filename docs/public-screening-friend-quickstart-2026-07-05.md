# 公開版スクリーニング クイックスタート 2026-07-05

## 公開版URL

```text
https://jimusaku-lab.github.io/us-options-risk-planner/
```

これは静的Webアプリです。証券会社やローカルAPIへ接続しません。

## まずサンプルを読み込む

1. 公開版URLを開く。
2. 画面上部の `候補` を開く。
3. `サンプルを読み込む` を押す。
4. 候補一覧にPSAMPLE1からPSAMPLE7が表示されることを確認する。

サンプルJSON:

```text
https://jimusaku-lab.github.io/us-options-risk-planner/samples/us-options-screening-sample-v1.json
```

サンプルは合成データです。実相場データではありません。

## 候補一覧で見る場所

- `確認優先度`: 見る順番の目安。売買推奨ではありません。
- `Level`: データ充足度。
- `戦略`: 持ち込みデータから見た分類。
- `建玉案`: 入力候補として確認できるか。
- `確認`: チェック済み数と必須未確認数。

## 候補詳細で見る場所

候補行の左にある開閉ボタンで詳細を開きます。

- チャート分析
- 戦略適性
- 戦略精度レビュー
- オプション候補と流動性
- 資金条件
- 建玉案レビュー前サマリー
- 不足データと警告

## チェックリストの使い方

戦略精度レビュー内のチェックリストは、見た項目を記録するためのものです。

- チェック済みは確認済みの記録です。
- 注文許可ではありません。
- 必須未確認が残る場合は、候補一覧や確認ゲートに表示されます。
- 確認メモには、証券会社画面やチャートで見たことを書けます。

## 根拠メモへの反映

`候補レビューを根拠メモへ反映` を押すと、確認内容をエントリー根拠メモへ追記します。

- 自動では反映されません。
- 既存メモは上書きされません。
- 反映後も画面で編集できます。

## 建玉案レビュー前ゲート

候補行の `LC`、`P`、`+` ボタンから建玉案レビューへ進む時、必須未確認が残っていると確認サマリーが出ます。

`未確認を理解して建玉案レビューへ進む` は、レビュー画面へ進むための確認です。実際の操作は証券会社画面で最終確認してください。

## 自分のデータを使う場合

`候補ファイル取込` からCSV/JSONを読み込めます。推奨は `us_options_screening_package.v1` 形式です。

入れないでください:

- APIキー
- トークン
- パスワード
- 口座ID完全値
- ローカル端末パス
- 操作指示に見える項目

## フィードバックしてほしい観点

- サンプル読込で迷ったところ
- 候補一覧で分かりにくい表示
- 戦略判定の理由で足りない情報
- チェックリストの文言
- 根拠メモへの反映の分かりやすさ
- 自分のデータを持ち込むために必要な項目
