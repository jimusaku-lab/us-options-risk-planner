# 米国株オプション建玉管理・リスク確認 ユーザーマニュアル

このマニュアルは、現在実装されている手入力型アプリの利用者向け説明です。サクソバンク証券の画面を見ながら、米国株式・米国株式オプションの建玉、口座余力、証拠金、プレミアム、年率、税務区分、反対売買、ホイール管理を記録・確認するために使います。

このアプリは投資助言、税務助言、自動売買、発注代行を行いません。最終判断と注文操作は、必ず利用者本人が証券会社画面で行ってください。

## 1. データ保存と公開版の注意

入力したデータは、利用者本人のブラウザ内に自動保存されます。GitHub Pagesや作成者側へ自動送信されません。

- 自動保存先はブラウザの `localStorage` です。
- 同じPCでも、別ブラウザではデータは共有されません。
- 別PCへは自動同期されません。
- ブラウザのサイトデータを削除すると、入力データも消えます。
- 大事な入力後、PC変更前、ブラウザ削除前には `JSON` でバックアップしてください。
- `CSV` は一覧確認用です。アプリへ戻すバックアップには使いません。
- `JSON` はアプリに復元できるバックアップ用です。

公開版では、外部通信を避けるため株価・為替の自動取得が無効になる場合があります。その場合は、Saxo TraderGO等で確認した数値を手入力してください。

## 2. DEMO / REAL の使い分け

画面上部で `DEMO` と `REAL` を切り替えます。

### DEMO

練習・検証用のワークスペースです。実取引ではありません。

SaxoTraderGOのデモ口座は、米国株式・米国株式オプションの価格や建玉損益はUSDで表示されますが、画面下部の口座通貨、現金残高、買付可能額、評価額、証拠金使用率はJPYベースで表示されます。

そのため、アプリではDEMOを本番N口座相当とは扱いません。表示は `DEMO / JPYベース` です。

DEMOではN口座のUSD残高、N口座証拠金使用率、N口座ホイール用USD台帳の検証は完全にはできません。P口座に近いJPYベースの練習用として使ってください。

### REAL

実資金の管理用ワークスペースです。DEMOとは別に保存されます。

REALでは、サクソバンク証券の口座構造に合わせて、P口座とN口座を分けて管理します。

- P口座: JPY決済
- N口座: USD決済

P口座とN口座の余力、証拠金、現金残高、建玉は合算しません。N口座のJPY換算は参考表示であり、税務上の確定損益ではありません。

## 3. 口座全体の余力・証拠金

`口座全体の余力・証拠金` には、Saxo TraderGO画面下部に出る口座全体の数値を入力します。これは個別銘柄ごとの値ではありません。

DEMOでは `DEMO / JPYベース` としてJPYベースの現金残高、証拠金使用率などを入力します。

REALでは、P口座とN口座を別々に入力します。

- P口座: JPY現金残高、買付可能額、口座純資産、必要証拠金余力、証拠金使用率など
- N口座: USD現金残高、買付可能額、口座純資産、必要証拠金余力、証拠金使用率など

この数値は、注文前NGや余力警告に使います。P口座の余力をN口座の建玉に使ったり、N口座の余力をP口座の建玉に使ったりする前提では計算しません。

## 4. 建玉ダッシュボード

登録した建玉は `建玉ダッシュボード` に表示されます。

主な列は以下です。

- 銘柄: NVDA、AMZNなど
- 状態: 注文前、建玉中、決済済み、権利行使済み、満期終了
- 口座: DEMO / JPYベース、本番P口座、本番N口座など
- 戦略: カバードコール、プット売り、カバードコール＋追加P売りなど
- 権利行使価格: CまたはPの権利行使価格
- 満期: オプションの満期日
- プレミアム: 受取プレミアム
- 使用分母: 年率換算の分母にしている資金
- 年率: 税前年率
- 警告: 注文前NGや注意件数

行をクリックすると、その建玉を選択して下のカード群に反映します。鉛筆アイコンを押すと建玉入力欄を開いて修正できます。削除アイコンを押すと建玉を削除します。

`決済済み`、`権利行使済み`、`満期終了` は履歴として残ります。通常は現在管理中の建玉が優先表示され、履歴は必要な時に表示します。

## 5. 新規建玉・建玉入力欄

`新規建玉` から新しい建玉を作成します。既存建玉はダッシュボードの鉛筆アイコンから編集します。

入力欄は大きく以下に分かれています。

### 5.1 銘柄・価格

- Saxo口座
- 建玉状態
- 戦略
- 銘柄ティッカー
- 現在株価
- 為替

株価取得を使う場合は、銘柄ティッカーを入力します。NVDA、AMZN、NFLXのような米国株ティッカーが基本です。NVIDIA、Amazon、アマゾンなど一部の名称は代表ティッカーへ自動変換されます。

ローカル版で株価・為替取得が有効な場合は、上部または入力欄の取得ボタンで現在値を反映できます。公開版では外部通信を避けるため無効になる場合があります。

### 5.2 保有株・取引資金

カバードコールやホイールで現物株を使う場合は、保有株数と現物取得単価を入力します。

プット売り単体では、現物株の保有入力は使いません。権利行使された場合に株を買い受ける資金は、分母比較や追加買付資金カードで確認します。

チケット表示証拠金は、Saxoの注文・決済チケットに出る必要証拠金を入力します。カバードコールのように保有株でカバーされ、チケット上の必要証拠金が0の場合は入力不要です。

証拠金バッファは、チケット表示証拠金をそのまま分母に使わず、余裕を見て何倍で見るかを設定するものです。

### 5.3 オプション脚

建玉日、満期日、権利行使価格、プレミアム、手数料を入力します。

カバードコールではC権利行使価格、Cプレミアム、C売りの方針を入力します。

C売りの方針:

- 株を売却されてもよい
- 株を残したい

プット売りではP権利行使価格、Pプレミアム、P売りの方針を入力します。

P売りの方針:

- 株を取得してもよい
- 株を取得したくない

プット売りは「割安なら株を買う入口」として使う場合と、「プレミアムだけ狙い、株は取得したくない」場合でリスク判断が変わります。この方針はシナリオ表示や注文前NGに使います。

取引手数料（USD）:
Saxoの取引チケットに表示される取引手数料をUSDで入力します。新規建玉と候補から作成した建玉では、初期値として `2.25 USD` が入ります。JPY手数料欄は、画面上でJPY手数料が確認できる場合だけ入力する補助的な任意入力です。

### 5.4 ルール・表示設定

ここでは注文前に決めておくルールと、表示上の前提を設定します。

利確ルールを使う:
途中で買い戻して利益確定する目安を持つ場合にONにします。プレミアム確保率を入力すると、反対売買判断で到達状況が表示されます。

損切りルールを使う:
株を取得したくないプット売り、株を残したいカバードコールなどで、途中で閉じる基準を持ちたい場合にONにします。

損切りルール種別:

- 買戻し価格: オプションの買戻し価格が一定以上になったら注意
- 株価ライン: 原資産株価が一定ラインに到達したら注意
- 損失額: 反対売買した場合の概算損益が一定の損失に達したら注意

ルールを入力しても自動発注はされません。反対売買判断カードや警告表示で、利用者が確認するための目安です。

主分母:
年率換算でどの資金を分母にするかを選びます。分母を変えると年率は大きく変わります。

NISA等 比較年率:
NISA等の非課税運用と比較するときの年率です。初期値は `9%` で、任意に変更できます。

### 5.5 現物株の譲渡記録

現物株を売却した、またはカバードコールで株を渡した場合に使います。

OFFの場合は、上場株式等の譲渡所得等は未集計として表示されます。

ONにすると以下を入力します。

- 譲渡の種類
- 譲渡日
- 譲渡株数
- 売却単価
- 取得単価
- 譲渡時為替
- 売却手数料

この入力は、オプション損益とは別に `上場株式等の譲渡所得等` として表示されます。オプション損益とは自動相殺しません。

## 6. サマリーカード

選択中の建玉について、上部に主要なカードが表示されます。

- 受取プレミアム
- 満期想定損益
- 使用分母
- 年率
- P権利行使時の追加買付資金
- 最大注意点

`満期想定損益` は、カバードコールで株を渡す想定がある場合に、現物譲渡損益とオプションプレミアムを合わせた概算を表示します。

年率カードは、税前 / 税引後を並べて表示します。日数は建玉日から満期日までの暦日数です。

## 7. 分母比較

分母比較は、同じ受取プレミアムでも、どの資金を分母にするかで年率がどう変わるかを見るための表です。

主な分母:

- 証券会社チケット証拠金ベース
- 現物株＋チケット証拠金
- 現物株＋使用証拠金ベース
- キャッシュセキュアードベース
- 保守的共通分母

プット売り単体の場合、現物株を持っていなければ `現物株なし` と表示されます。この場合の年率の分子は、基本的にオプションの受取プレミアムです。

## 8. 年率換算の計算根拠

分母比較の下に `年率換算の計算根拠` があります。通常は折りたたまれており、必要な時だけ開きます。

税前年率の基本式:

```text
税前年率 = 受取プレミアム ÷ 使用分母 × 365 ÷ 建玉日から満期日までの日数 × 100
```

税引後年率の基本式:

```text
税引後年率 = 税引後利益 ÷ 使用分母 × 365 ÷ 建玉日から満期日までの日数 × 100
```

N口座ではUSD同士で主計算します。USD/JPYを更新しても、USD建て年率は変わりません。JPY表示は参考換算です。

## 9. 反対売買判断

反対売買判断は、売り建てオプションを途中で買い戻して閉じるかどうかを見るカードです。通常は折りたたまれています。

途中決済を検討するときだけ開き、Saxoの決済チケットに出る買戻し価格を入力します。

表示される内容:

- 建てた時のプレミアム
- 現在の買戻し価格
- 手数料控除
- 今閉じた場合の概算損益
- プレミアム確保率
- 利確ルール判定
- 損切りルール判定

手数料は、建てた時と買い戻す時の概算を控除します。

入力しても自動発注はされません。あくまで「今閉じるとどの程度の損益になるか」を見るためのものです。

## 10. 税務関連カード

税務表示は概算です。確定申告用の税額ではありません。

### オプション税引後カード

オプション損益を `先物取引に係る雑所得等` として扱う前提で概算します。

表示内容:

- 税前利益
- 手数料・費用控除後利益
- 課税対象利益
- 想定税額
- 税引後利益
- 税前年率
- 税引後年率

### NISA等の非課税口座比較

同じ分母・同じ日数で、NISA等の比較対象年率ならどれくらいの利益になるかを見ます。

表示内容:

- NISA等の比較対象年率
- NISA等で同じ分母・同じ日数なら
- オプション税引後利益との差額
- NISA等を上回るための税前利益
- 必要な税前年率

### 税務区分別の内訳

オプション損益と現物株売却損益を別区分で表示します。

- 先物取引に係る雑所得等
- 上場株式等の譲渡所得等
- 配当所得・外国税額控除

このアプリでは、株式等に係る譲渡所得等と先物取引に係る雑所得等を自動で損益通算しません。

`履歴集計` を開くと、決済済み、権利行使済み、満期終了になった建玉の税務区分別集計を確認できます。

## 11. シナリオカード

シナリオカードは、満期時に株価がどの位置にあるかによって、どういう状態になるかを整理するものです。

プット売りの場合:

- 株を取得せず終わるケース
- 株取得に近づくケース
- 株を取得し含み損を抱えるケース

カバードコールの場合:

- 株を渡さず終わるケース
- 権利行使価格付近のケース
- 株を渡すケース

カバードコール＋追加P売りの場合は、C側とP側の両方を意識します。

シナリオは損益を確定するものではありません。満期時の状態と、満期前に考えるべき行動を整理するための表示です。

## 12. 満期ペイオフチャート

満期ペイオフチャートは、満期時の株価ごとに、概算損益がどう変化するかを可視化します。

- 横軸: 満期時の株価
- 縦軸: 概算損益

プット売りでは、株価が権利行使価格を下回ると株を取得する可能性があります。チャートの下側は、取得後に含み損を抱える可能性を示す領域です。実現損益として確定するわけではありません。

カバードコールでは、株価が権利行使価格を上回ると株を渡す可能性があります。上方向の利益がどこで頭打ちになるかを見るために使います。

## 13. リスク警告と注文前チェックリスト

リスク警告は、入力内容から注意すべき点を表示します。

例:

- 証拠金使用率が高い
- 現金残高が不足している可能性がある
- 裸コール部分がある
- N口座のJPY換算は参考表示
- P口座で取得した株式が残っている

警告は注文前に確認するためのものです。発注を自動で止めるものではありません。

注文前チェックリストは、利用者が自分で確認した項目にチェックを入れるためのものです。最初から全チェック済みにするものではありません。

## 14. N口座ホイール管理

ホイール管理は、原則としてN口座内でUSDベースで回す前提です。

基本の流れ:

```text
N口座でUSD保有
→ N口座でプット売り
→ 権利行使でN口座に株式取得
→ N口座でカバードコール
→ 権利行使または売却でN口座にUSDが戻る
→ 再購入または再度プット売り
```

P口座でプット売りして株式を取得した場合は、P口座からN口座へ株式移管し、N口座ホイールへ合流させる流れを想定します。

```text
P口座でプット売り
→ P口座で株式取得
→ P口座からN口座へ株式移管
→ N口座でカバードコール
```

P→N株式移管は売却ではありません。オプション損益、現物譲渡損益、為替損益として扱いません。株数と取得単価をN口座側へ引き継ぎます。

ホイール管理では銘柄ごとに以下を表示します。

- 現在フェーズ
- 累積プレミアム
- 株式売買損益
- 累積手数料
- 累積損益
- 現在株数
- 平均取得単価
- 次の候補アクション

色付きステップで、現在どの段階にいるかを確認できます。未売却株の含み損益は、ホイールの実現損益には混ぜません。

## 15. 候補リスト

候補リスト機能が有効な画面では、TradingView等で作成した候補JSON/CSVを取り込み、建玉案の入口として使えます。

候補リストは、Saxo APIなしで候補銘柄を整理するための補助機能です。候補から作成された建玉案も、最終的にはSaxo画面の数値を見て手入力・確認してください。

## 16. CSV / JSON / 復元 / データ削除

### CSV

CSVは一覧確認用です。Excelやスプレッドシートで建玉一覧を見るために使います。CSVからアプリへ復元する機能ではありません。

### JSON

JSONはアプリへ戻せるバックアップです。以下が含まれます。

- DEMO/REALの建玉
- 口座全体の入力値
- チェックリスト
- ホイールサイクル
- ホイールイベント
- P→N株式移管記録

重要な入力後、PC変更前、ブラウザ整理前にはJSONで保存してください。

### 復元

JSONバックアップを読み込んで、アプリ内データを復元します。復元すると現在のワークスペースデータが置き換わるため、必要に応じて先にJSONを保存してください。

### データ画面

データ画面では、この端末のブラウザ内に保存された入力データを削除できます。知人に試してもらう場合や、端末を共有している場合は、使い終わった後に削除してください。

## 17. よくある確認

### 年率換算の日数は何ですか

建玉日から満期日までの暦日数です。営業日数ではありません。

### プット売りの年率の分子は何ですか

基本的には受取プレミアムです。手数料・税金を反映した税引後年率では、手数料や概算税額を差し引いた値を使います。

### 現物株を持っていないプット売りで「現物株なし」と出るのは正常ですか

正常です。プット売り単体では現物株を持っていないため、現物株時価は分母に入りません。

### カバードコールでチケット表示証拠金は必要ですか

保有株でカバーされ、Saxoのチケット上の必要証拠金が0なら入力不要です。アプリ上も0として扱います。

### N口座のJPY表示は何ですか

参考換算です。N口座の主計算はUSDです。JPY換算は現在の表示用USD/JPYによる目安で、円転または税務上の確定損益ではありません。

### DEMO口座でN口座の検証はできますか

完全にはできません。DEMOはJPYベースの検証用として扱います。本番N口座のUSD残高管理、JPY→USD資金振替、USD取得レート管理の検証には不十分です。

## 18. 利用時の基本手順

1. DEMOまたはREALを選ぶ。
2. 口座全体の余力・証拠金を入力する。
3. 新規建玉を作る。
4. 口座、状態、戦略、銘柄、株価、為替を入力する。
5. オプション脚、プレミアム、手数料を入力する。
6. 必要に応じて利確・損切りルールを設定する。
7. 現物売却やC権利行使で株を渡した場合は、現物株の譲渡記録をONにする。
8. ダッシュボードで建玉を選択し、サマリー、分母比較、年率根拠、税務区分、シナリオ、チャート、警告を確認する。
9. 途中決済を検討するときは、反対売買判断を開いて買戻し価格を入力する。
10. 重要な入力後はJSONでバックアップする。
