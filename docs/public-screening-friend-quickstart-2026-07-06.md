# 公開版スクリーニング 友人向けクイックスタート 2026-07-06

## 公開版URL

```text
https://jimusaku-lab.github.io/us-options-risk-planner/
```

これは静的Webアプリです。証券会社やローカル取得基盤へ直接接続しません。サンプルは合成データで、実相場データではありません。

## まず試してほしい順番

1. 公開版URLを開く。
2. 画面上部の `候補` を開く。
3. `サンプルを読み込む` を押す。
4. 候補一覧に `PSAMPLE1` から `PSAMPLE7` が表示されることを確認する。
5. Level 1からLevel 4の違いを見る。
6. `PSAMPLE4` の詳細を開く。
7. チャート分析、戦略適性、オプション候補、資金条件、建玉案レビューを確認する。
8. `手動確認ハンドオフ` を見る。
9. `手動確認メモをコピー` と `レビューJSONを書き出す` の場所を確認する。
10. `根拠メモへ反映` を押し、候補理由がメモへ追記されることを確認する。

## 見てほしいポイント

- `確認優先度` は見る順番の目安に見えるか。売買推奨に見えないか。
- `Level` の意味が分かるか。
- `建玉案レビュー可` が注文可能に見えないか。
- `手動確認ハンドオフ` が、Saxo TraderGO等の証券会社画面で最終確認するためのメモに見えるか。
- 根拠メモへの反映が「自動上書き」ではなく、明示操作での追記に見えるか。
- PCとスマホで見づらい箇所がないか。

## 用語の読み方

| 表示 | 意味 |
| --- | --- |
| Level 1 | 銘柄と価格中心。チャートやオプション情報が不足 |
| Level 2 | チャート確認ができる。オプションBid/Askなどは不足 |
| Level 3 | オプション候補を確認できる。資金条件は不足する場合あり |
| Level 4 | 資金条件まで含めて建玉案レビューに進める |
| 候補 / fit | 分類上の候補。売買推奨ではない |
| 建玉案レビュー可 | 入力候補として確認できる状態。注文可能ではない |
| 入力候補として確認済み | チェックリスト上の確認記録。注文可能ではない |
