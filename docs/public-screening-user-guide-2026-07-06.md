# 公開版スクリーニング利用ガイド 2026-07-06

## 位置づけ

公開版は静的Webアプリです。証券会社や外部取得基盤へ直接接続しません。スクリーニングv1は、試用フィードバックに出せるリリース候補です。

利用できる入力は次の3つです。

- 画面からの手入力
- 既存の候補CSV/JSON
- `us_options_screening_package.v1` JSON

戦略適性、オプション候補、資金条件、建玉案レビューは、持ち込みデータを整理するための参考分類です。投資助言や利益保証ではありません。最終確認は証券会社画面、チャート、資金条件、オプションチェーンで行ってください。

## サンプルJSON

候補画面の `サンプルを読み込む` を押すと、このサンプルを画面から直接読み込めます。

配布サンプル:

```text
public/samples/us-options-screening-sample-levels-v1.json
```

GitHub Pages上の想定パス:

```text
https://jimusaku-lab.github.io/us-options-risk-planner/samples/us-options-screening-sample-levels-v1.json
```

サンプルは合成値のみを使ったデモデータです。実相場データではありません。

## 取込手順

1. アプリを開く。
2. `候補` を開く。
3. まずは `サンプルを読み込む` を押す。
4. 候補一覧でLevel、戦略適性、建玉案ステータスを確認する。
5. 各行の詳細カードを開き、チャート分析、オプション候補、資金条件、不足データ、警告を確認する。
6. 戦略精度レビューと建玉案レビュー前チェックを確認する。
7. Level 4例の詳細で `手動確認ハンドオフ` を確認する。
8. 必要に応じて `手動確認メモをコピー`、`レビューJSONを書き出す`、`根拠メモへ反映` を確認する。

取込だけでは建玉入力へ自動反映されません。候補から入力候補を作る場合も、画面上で内容を確認してから操作してください。`draft_ready` は注文可能という意味ではなく、レビュー前チェックを始められるだけのデータが揃っている状態です。

## データ充足Level

| Level | 意味 | 主な不足例 |
| --- | --- | --- |
| Level 1 | 銘柄と価格だけがある | チャート、オプション、資金条件 |
| Level 2 | チャート分析またはOHLCVがある | Bid/Ask付きオプション候補、資金条件 |
| Level 3 | オプション候補とBid/Askがある | availableCashUSD等の資金条件 |
| Level 4 | 資金条件まであり建玉案レビューに進める | 最終価格、口座制約、利用者判断、レビュー前チェック |

Lastだけのオプション価格は保守価格には使いません。買い建てはAsk、売り建てはBidを保守価格候補として扱います。MidとLastは参考値です。

## サンプルで確認できること

- チャート根拠が弱い候補は `fit` にならない。
- Bid/Askがない候補はLevel 3に進まない。
- 資金条件がない候補は建玉案レビューが準備完了にならない。
- 資金不足の候補は建玉案ステータスが抑止される。
- 100株不足、許容損失超過、Lastのみ、Bid/Ask不足は建玉案レビュー準備完了にしない。
- 上級戦略は手動確認レビューとして表示される。
- チェック済み数、必須未確認数、建玉案レビュー前ゲートを確認できる。
- 手動確認ハンドオフで、証券会社画面で最終確認するためのメモと安全なレビューJSONを確認できる。

## 実データを使うときの注意

- 認証情報、APIキー、口座ID完全値、注文パスワードをJSONに入れない。
- 個人の口座情報を共有用サンプルに含めない。
- 再配布できない相場データは公開リポジトリへ入れない。
- 候補分類を売買判断として扱わない。
- 実際の操作前に、証券会社画面の価格、手数料、口座余力、リスクを確認する。
