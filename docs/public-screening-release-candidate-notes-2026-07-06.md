# 公開版スクリーニング v1 リリース候補ノート 2026-07-06

## ステータス

公開版スクリーニングv1は、友人向け試用フィードバックに出せるリリース候補です。

公開版で確認できる範囲:

- 合成サンプル読込
- Level 1-4表示
- チャート分析
- 戦略適性
- オプション候補
- 資金条件
- 建玉案レビュー
- 手動確認ハンドオフ
- メモコピー
- レビューJSON書き出し
- エントリー根拠メモへの明示反映

## リリース候補の意味

このRCは、候補分類とレビュー補助を試してもらうためのものです。

- 投資助言ではありません。
- 売買推奨ではありません。
- 注文可能判定ではありません。
- 発注、注文変更、注文取消、権利行使、取引ロック解除はありません。
- 最終確認は証券会社画面で利用者本人が行います。

## 既知制約

- サンプルは合成データです。
- 公開版は証券会社やローカル取得基盤へ直接接続しません。
- 実オプション相場のBid/Ask/OI/Volume/IV/Greeks成功系は、ローカル版でUSオプション相場権限付与後に再確認します。
- Lastのみの価格は保守価格として扱いません。
- 複数脚コンボ、シンセティック、上級戦略は手動確認レビュー止まりです。

## 試用で回収したいこと

- サンプル読込まで迷わないか。
- Level表示の意味が分かるか。
- 確認優先度や戦略候補が売買推奨に見えないか。
- `建玉案レビュー可` が注文可能に見えないか。
- 手動確認ハンドオフが証券会社画面で確認しやすいか。
- 根拠メモへの反映が役に立つか。
- PC/スマホで見づらい箇所がないか。
- 自分のデータを持ち込む時に不足する項目が何か。
