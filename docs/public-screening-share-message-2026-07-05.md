```text
米国株オプション建玉管理アプリの公開版スクリーニングを試せるようにしました。

URL:
https://jimusaku-lab.github.io/us-options-risk-planner/

まず試す手順:
1. 画面上部の「候補」を押す
2. 「サンプルを読み込む」を押す
3. 候補一覧、候補詳細、戦略精度レビュー、チェックリストを見てください
4. LC / P / + から建玉案レビュー前の確認ゲートも見られます

見てほしい点:
- サンプル読込で迷わないか
- 候補一覧で見る順番が分かるか
- 戦略判定の理由が納得できるか
- チェックリストの文言が分かりやすいか
- 根拠メモへの反映が使いやすいか
- 自分のCSV/JSONを持ち込むなら、どの項目が必要そうか

注意:
- サンプルは合成データで、実相場データではありません
- 候補は売買推奨ではなく、持ち込みデータの確認用分類です
- 認証情報、APIキー、口座ID、注文パスワード、個人口座データは入れないでください
- 実際の価格や資金、操作内容は証券会社画面で最終確認してください
```
